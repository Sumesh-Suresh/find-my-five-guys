How these rankings were built ›

We pulled contributor activity straight from the GitHub API — every commit landed on the master branch over the last 90 days, restricted to commits whose CI checks all came back green. From an initial pool of 7,150 commits we filtered down to 2,671 that met the bar for evaluation.

7,150 → 2,671 commits
Step 3

Step 4
Aggregate
Sum points per author

Each surviving commit was sent to Gemini Flash 3.1 with its message and per-file diff summary, and the model returned a score from 1 to 10. The features considered were:

  • Commit message — the author's stated intent and rationale.
  • Merge-commit flag — whether the commit is a pure merge with no real change.
  • Files changed — total number of files touched by the commit.
  • Additions / deletions / total changes — overall LOC churn across the commit.
  • Per-file path & status — added, modified, deleted, or renamed (incl. previous filename).
  • Per-file additions, deletions & changes — LOC churn for each individual file.
  • File diffs (patches) — the actual code changes, truncated to ~2,000 chars per file.

Scoring rubric

  • 1Noise / whitespace / reverted
  • 2Trivial — typo, format, version bump
  • 3Very minor — single-line cosmetic
  • 4Minor localized refactor
  • 5Routine feature or bug fix
  • 6Solid, well-scoped change
  • 7Strong — important code, good tests
  • 8High impact & thoughtful
  • 9Critical & excellent
  • 10Exemplary — rare, standard-setting

Finally we grouped every scored commit by author and summed the points. The five highest totals are the leaderboard above.
